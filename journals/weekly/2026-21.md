## 8. Recurring Lessons-Pending (for Self-Learning)

Listed by severity. Evidence gathered this week.

### MUST-FIX (operational reliability)

1. **Intraday CB equity write guard (PENDING_BROKER rows):** When `paper_sim` has `PENDING_BROKER` rows, broker account equity includes cash debited for the order but the sim ledger doesn't yet have a position — producing a spurious drawdown. Intraday routines must skip the CB equity write or use `paper_sim.portfolio_equity()` rather than `broker.account_snapshot()` when any `PENDING_BROKER` rows exist. Evidence: 2026-05-19 spurious HALF state, 5 URGENT notifications for a non-event.

2. **`positions.json` stop/target persistence under alpaca-mirror:** When the reconciler rebuilds `positions.json` from the Alpaca mirror, `stop_loss` and `take_profit` are set to `null`, making the deterministic `portfolio_health` stop check inert. All week, stop monitoring was advisory-by-hand (manual cross-check vs log.csv entries). This is a silent safety degradation: automated stops are off without any explicit notice. Fix: persist entry stops/targets in a side-file (e.g., `trades/paper/position_meta.json`) that the reconciler re-reads rather than wiping.

### HIGH priority (data / signal quality)

3. **Post-earnings gap guard (mechanical NO_TRADE on stale signal):** Today (2026-05-21) the deterministic engine correctly fired a WMT ENTRY on the 2026-05-20 pre-earnings bar. The NO_TRADE required judgment ("signal price is stale") rather than a mechanical gate. A production-quality system should detect that the `signal_bar_date` is the session BEFORE a known earnings release and flag the signal as `stale_post_event: true`, making the NO_TRADE deterministic. This would prevent a future routine run from re-entering into a gap without human attention.

### MEDIUM priority (operational quality)

4. **`archive_routine_logs.py` legacy filename tolerance:** `20260518_133639Z_market_open_noop.md` (compact `YYYYMMDD_HHMMSSZ` stem) caused non-fatal exit errors across all 5 days. Archiver should quarantine (not abort) files that don't match the expected pattern. The malformed file is pre-existing; a one-off rename or tolerance fix is needed.

5. **Sim-vs-Alpaca equity gap monitoring:** Gap widened to −$1,861 on 2026-05-21 EOD (mark-timing difference — sim uses sharper late-day marks; Alpaca marks earlier). Narrowed to manageable levels by 2026-05-22 open. Position-level reconcile was always clean, so this is a cosmetic/informational gap, but it grows without bound if late-day fills systematically differ. Investigate whether sim `latest_quotes_for_positions` timestamps systematically differ from Alpaca account marks at the close.
